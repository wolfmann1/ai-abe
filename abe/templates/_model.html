Don't see the model you want? Install it yourself with ollama pull <model> (names are listed at ollama.com/library) and reload this page. Or type its name in the model box: when you save, ABE will ask Ollama to download it and show the progress on the agent's page. Models are several gigabytes, so this can take a while. If the download fails, run ollama pull <model> in a terminal instead. To pick a size that fits your graphics card, see docs/choosing-a-local-model.md.

OpenRouter: buy credits at openrouter.ai, create a key, set it as OPENROUTER_API_KEY, and enter the model ID exactly as OpenRouter lists it (provider/model). Other OpenAI-compatible server: enter its address, for example http://localhost:1234/v1 for LM Studio. The extractive option needs no model and gives a baseline to compare against.
