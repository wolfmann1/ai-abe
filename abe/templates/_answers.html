Custom effort is sent to the model as an instruction in the system prompt. It doesn't switch on a model's built-in reasoning mode; that setting is on the roadmap.

Choosing a level sets passages per question and answer length; you can fine-tune both afterwards under Edit agent → Search and Model → Advanced.

Questions with no matching passage at all are still declined before the model is asked. Run the test set after changing any of these to see what they did.
